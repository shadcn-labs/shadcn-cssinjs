## Use shadcn/create

<Steps>

### Build Your Preset

Open [shadcn/create](/create?template=react-router) and build your preset visually. Choose your style, colors, fonts, icons, and more.

<Button asChild size="sm">
  <Link
    href="/create?template=react-router"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    Open shadcn/create
  </Link>
</Button>

### Create Project

Click `Create Project`, choose your package manager, and copy the generated command:

```bash
pnpm dlx shadcn@latest init --preset [CODE] --template react-router
```

### Add Components

Add a component from the registry:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import and render the component in a route:

```tsx title="app/routes/home.tsx"
import { Button } from "@/components/ui/button/button";

export default function Home() {
  return (
    <div className="flex min-h-screen items-center justify-center">
      <Button>Click me</Button>
    </div>
  );
}
```

</Steps>

## Existing Project

### Prerequisites

- [Node.js](https://nodejs.org/) 18.17 or later
- A package manager: `pnpm`, `npm`, `yarn`, or `bun`

<Steps>

### Create Project

If you need a new React Router project, create one with the official template:

```bash
pnpm create react-router@latest my-app
cd my-app
```

### Install dependencies

Install StyleX, Base UI primitives, and the StyleX build tools:

```bash
pnpm add @stylexjs/stylex @base-ui/react
pnpm add -D @stylexjs/babel-plugin @stylexjs/postcss-plugin @babel/preset-typescript @tailwindcss/postcss tailwindcss @types/node vite-plugin-babel
```

### Configure Vite

React Router v7 uses Vite. Update `vite.config.ts` with the StyleX Babel plugin and path resolution:

```ts title="vite.config.ts"
import path from "node:path";
import { reactRouter } from "@react-router/dev/vite";
import babel from "vite-plugin-babel";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    reactRouter(),
    babel({
      filter: /\.[jt]sx?$/,
      babelConfig: {
        presets: ["@babel/preset-typescript"],
        plugins: [
          [
            "@stylexjs/babel-plugin",
            {
              runtimeInjection: false,
              styleResolution: "property-specificity",
              unstable_moduleResolution: {
                type: "commonJS",
                rootDir: process.cwd(),
              },
            },
          ],
        ],
      },
    }),
  ],
  resolve: {
    alias: {
      "~": path.resolve(__dirname, "./app"),
      "@": path.resolve(__dirname, "./app"),
    },
  },
});
```

### Configure PostCSS

Create `postcss.config.mjs` at your project root. Place `@stylexjs/postcss-plugin` **before** Tailwind:

```js title="postcss.config.mjs"
const config = {
  plugins: {
    "@stylexjs/postcss-plugin": {
      include: ["app/**/*.{js,jsx,ts,tsx}"],
      useCSSLayers: true,
      styleResolution: "property-specificity",
      runtimeInjection: false,
      unstable_moduleResolution: { type: "commonJS", rootDir: process.cwd() },
    },
    "@tailwindcss/postcss": {},
  },
};

export default config;
```

### Add the StyleX directive

Add `@stylex;` to your global stylesheet:

```css title="app/app.css"
@import "tailwindcss";

@stylex;
```

Ensure `app.css` is imported in `app/root.tsx`:

```tsx title="app/root.tsx"
import stylesheet from "~/app.css?url";

export const links = () => [{ rel: "stylesheet", href: stylesheet }];
```

### Configure path aliases

Ensure `tsconfig.json` specifies path aliases for `@/*` and `~/*`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "~/*": ["./app/*"],
      "@/*": ["./app/*"]
    }
  }
}
```

### Add the design tokens

Install the shared design tokens from the registry:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/stylex-tokens.json
```

### Install a component

Add a component using the shadcn CLI:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import and render the component in a route:

```tsx title="app/routes/home.tsx"
import { Button } from "@/components/ui/button/button";

export default function Home() {
  return (
    <div className="flex min-h-screen items-center justify-center">
      <Button>Click me</Button>
    </div>
  );
}
```

</Steps>
