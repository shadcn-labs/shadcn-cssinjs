title: Manual Installation
description: Framework-agnostic manual setup for StyleX and shadcn-cssinjs.
---

This guide covers how to set up shadcn-cssinjs in any React project regardless of your framework or bundler (such as Webpack, Rollup, Vite, or esbuild).

## How StyleX Works

StyleX does not use a runtime style injection mechanism in production. Instead, it relies on a compile-time build pipeline that transforms `stylex.create` and `stylex.props` calls into deterministic atomic CSS.

There are two integration approaches depending on your build tool:

- **`@stylexjs/unplugin`** — Recommended for Vite, Rollup, Webpack, esbuild, Rspack, and Bun. A universal bundler plugin that handles both compilation and CSS output.
- **`@stylexjs/babel-plugin` + `@stylexjs/postcss-plugin`** — For Next.js and other Babel-based pipelines. The Babel plugin transforms the source, and the PostCSS plugin extracts the CSS.

## Prerequisites

- [Node.js](https://nodejs.org/) 18.17 or later
- A package manager: `pnpm`, `npm`, `yarn`, or `bun`

## Option A: Using `@stylexjs/unplugin` (Vite, Rollup, Webpack, esbuild)

<Steps>

<Step>Install dependencies</Step>

Install the StyleX runtime, Base UI primitives, and the StyleX compiler:

```bash
pnpm add @stylexjs/stylex @base-ui/react
pnpm add -D @stylexjs/unplugin
```

<Step>Configure your bundler</Step>

Add the StyleX unplugin to your bundler configuration. The exact syntax varies by bundler:

**Vite:**

```ts title="vite.config.ts"
import react from "@vitejs/plugin-react";
import stylex from "@stylexjs/unplugin";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [stylex.vite({ useCSSLayers: true }), react()],
});
```

**Rollup:**

```js title="rollup.config.js"
import stylex from "@stylexjs/unplugin";

export default {
  plugins: [stylex({ useCSSLayers: true })],
};
```

**Webpack:**

```js title="webpack.config.js"
const stylex = require("@stylexjs/unplugin/webpack");

module.exports = {
  plugins: [stylex({ useCSSLayers: true })],
};
```

<Step>Add the StyleX directive</Step>

Create a CSS file and add the `@stylex;` marker:

```css title="src/index.css"
@stylex;
```

Import this stylesheet in your application entry point.

<Step>Configure TypeScript path aliases</Step>

If using `@/*` imports, ensure `tsconfig.json` contains:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

<Step>Add the design tokens</Step>

Install the shared tokens from the registry into `components/ui/tokens.stylex.ts`:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/stylex-tokens.json
```

<Step>Install and use a component</Step>

Add a component with the shadcn CLI:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import the component into your application:

```tsx
import { Button } from "@/components/ui/button/button";

export function App() {
  return <Button>Click me</Button>;
}
```

</Steps>

## Option B: Using Babel + PostCSS (Next.js)

<Steps>

<Step>Install dependencies</Step>

Install the StyleX runtime, Base UI primitives, and the build-time plugins:

```bash
pnpm add @stylexjs/stylex @base-ui/react
pnpm add -D @stylexjs/babel-plugin @stylexjs/postcss-plugin postcss
```

<Step>Configure Babel</Step>

Create `babel.config.js` at the root of your project:

```js title="babel.config.js"
const path = require("path");
const dev = process.env.NODE_ENV !== "production";

module.exports = {
  plugins: [
    [
      "@stylexjs/babel-plugin",
      {
        dev,
        runtimeInjection: false,
        enableInlinedConditionalMerge: true,
        treeshakeCompensation: true,
        aliases: { "@/*": [path.join(__dirname, "*")] },
        unstable_moduleResolution: { type: "commonJS" },
      },
    ],
  ],
};
```

Key configuration options:

- `runtimeInjection: false`: Disables runtime `<style>` injection so all styles are cleanly extracted to static CSS.
- `enableInlinedConditionalMerge: true`: Optimizes conditional style merging.
- `treeshakeCompensation: true`: Compensates for tree-shaking to ensure styles are not lost.
- `unstable_moduleResolution`: Configures how module paths and cross-file variables are resolved.

<Step>Configure PostCSS</Step>

Create `postcss.config.js` at your project root:

```js title="postcss.config.js"
const babelConfig = require("./babel.config");

module.exports = {
  plugins: {
    "@stylexjs/postcss-plugin": {
      include: [
        "src/**/*.{js,jsx,ts,tsx}",
        "app/**/*.{js,jsx,ts,tsx}",
        "components/**/*.{js,jsx,ts,tsx}",
      ],
      babelConfig: {
        babelrc: false,
        parserOpts: { plugins: ["typescript", "jsx"] },
        plugins: babelConfig.plugins,
      },
      useCSSLayers: true,
    },
  },
};
```

<Step>Add the StyleX directive to your global stylesheet</Step>

In your main CSS file (e.g., `globals.css` or `index.css`), add the `@stylex;` marker:

```css title="src/globals.css"
@stylex;
```

When PostCSS runs, `@stylex;` will be replaced with all extracted component CSS rules.

<Step>Configure TypeScript path aliases</Step>

If using `@/*` imports, ensure `tsconfig.json` contains:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

<Step>Add the design tokens</Step>

Install the shared tokens from the registry into `components/ui/tokens.stylex.ts`:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/stylex-tokens.json
```

<Step>Install and use a component</Step>

Add a component with the shadcn CLI:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import the component into your application:

```tsx
import { Button } from "@/components/ui/button/button";

export function App() {
  return <Button>Click me</Button>;
}
```

</Steps>

## Existing Project

To retrofit StyleX into any existing application:

1. **Choose your integration approach.** Use `@stylexjs/unplugin` for Vite/Rollup/Webpack/esbuild, or `@stylexjs/babel-plugin` + `@stylexjs/postcss-plugin` for Babel-based pipelines.
2. **Configure the plugin** in your build tool's configuration.
3. **Insert `@stylex;`** into your root CSS file.
4. **Install design tokens:**
   ```bash
   npx shadcn@latest add https://shadcn-cssinjs.com/r/stylex-tokens.json
   ```
