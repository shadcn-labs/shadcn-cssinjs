## Use shadcn/create

<Steps>

### Build Your Preset

Open [shadcn/create](/create?template=next) and build your preset visually. Choose your style, colors, fonts, icons, and more.

<Button asChild size="sm">
  <Link
    href="/create?template=next"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    Open shadcn/create
  </Link>
</Button>

### Create Project

Click `Create Project`, choose your package manager, and copy the generated command:

```bash
pnpm dlx shadcn@latest init --preset [CODE] --template next
```

### Add Components

Add a component from the registry:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import and use it in your page:

```tsx title="app/page.tsx"
import { Button } from "@/components/ui/button/button";

export default function Home() {
  return (
    <main>
      <Button>Click me</Button>
    </main>
  );
}
```

</Steps>

## Use the CLI

<Steps>

### Create Project

Run the `init` command to scaffold a new Next.js project with StyleX and Base UI:

```bash
pnpm dlx shadcn@latest init -t next
```

### Add Components

Add a component from the registry:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

The component is placed in `components/ui/button/`. Import and use it in your page:

```tsx title="app/page.tsx"
import { Button } from "@/components/ui/button/button";

export default function Home() {
  return (
    <main>
      <Button>Click me</Button>
    </main>
  );
}
```

</Steps>

## Existing Project

### Prerequisites

- [Node.js](https://nodejs.org/) 18.17 or later
- A package manager: `pnpm`, `npm`, `yarn`, or `bun`

<Steps>

### Create Project

If you need a new Next.js project, create one with `create-next-app`. Otherwise, skip this step.

```bash
pnpm create next-app@latest my-app --typescript --eslint --app --src-dir=false --import-alias="@/*"
cd my-app
```

### Install dependencies

Install StyleX runtime, Base UI primitives, and the StyleX compilation toolchain:

```bash
pnpm add @stylexjs/stylex @base-ui/react
pnpm add -D @stylexjs/babel-plugin @stylexjs/postcss-plugin postcss
```

### Configure Babel

StyleX transforms component styles using Babel. Create `babel.config.js` at the root of your project:

```js title="babel.config.js"
const path = require("path");
const dev = process.env.NODE_ENV !== "production";

module.exports = {
  presets: ["next/babel"],
  plugins: [
    [
      "@stylexjs/babel-plugin",
      {
        dev,
        runtimeInjection: false,
        enableInlinedConditionalMerge: true,
        treeshakeCompensation: true,
        aliases: { "@/*": [path.join(__dirname, "*")] },
        unstable_moduleResolution: { type: "commonJS" },
      },
    ],
  ],
};
```

<Callout type="warn">
  Adding a `babel.config.js` opts Next.js out of the Turbopack compiler. Run
  `next dev` and `next build` without the `--turbopack` flag so the Babel
  transformation pipeline runs.
</Callout>

### Configure PostCSS

Create `postcss.config.js` at the root of your project. The PostCSS plugin extracts the compiled CSS:

```js title="postcss.config.js"
const babelConfig = require("./babel.config");

module.exports = {
  plugins: {
    "@stylexjs/postcss-plugin": {
      include: [
        "src/**/*.{js,jsx,ts,tsx}",
        "app/**/*.{js,jsx,ts,tsx}",
        "pages/**/*.{js,jsx,ts,tsx}",
        "components/**/*.{js,jsx,ts,tsx}",
      ],
      babelConfig: {
        babelrc: false,
        parserOpts: { plugins: ["typescript", "jsx"] },
        plugins: babelConfig.plugins,
      },
      useCSSLayers: true,
    },
    autoprefixer: {},
  },
};
```

### Add the StyleX directive

Add `@stylex;` to your global stylesheet. The PostCSS plugin replaces this directive with the compiled component CSS:

```css title="app/globals.css"
@stylex;
```

### Configure path aliases

Ensure your `tsconfig.json` has the path alias configured for `@/*`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

### Add the design tokens

Every component references a shared set of design tokens. Install them once into `components/ui/tokens.stylex.ts`:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/stylex-tokens.json
```

### Install a component

Add any component from the registry:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import and render the component:

```tsx title="app/page.tsx"
import { Button } from "@/components/ui/button/button";

export default function Home() {
  return (
    <main>
      <Button>Click me</Button>
    </main>
  );
}
```

</Steps>
