## Use shadcn/create

<Steps>

### Build Your Preset

Open [shadcn/create](/create?template=vite) and build your preset visually. Choose your style, colors, fonts, icons, and more.

<Button asChild size="sm">
  <Link
    href="/create?template=vite"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    Open shadcn/create
  </Link>
</Button>

### Create Project

Click `Create Project`, choose your package manager, and copy the generated command:

```bash
pnpm dlx shadcn@latest init --preset [CODE] --template vite
```

### Add Components

Add a component from the registry:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import and render the component:

```tsx title="src/App.tsx"
import { Button } from "@/components/ui/button/button";

export function App() {
  return (
    <div>
      <Button>Click me</Button>
    </div>
  );
}

export default App;
```

</Steps>

## Existing Project

### Prerequisites

- [Node.js](https://nodejs.org/) 18.17 or later
- A package manager: `pnpm`, `npm`, `yarn`, or `bun`

<Steps>

### Create Project

If you need a new Vite React TypeScript project, run:

```bash
pnpm create vite my-app --template react-ts
cd my-app
```

### Install dependencies

Install StyleX, Base UI primitives, and the StyleX compiler:

```bash
pnpm add @stylexjs/stylex @base-ui/react
pnpm add -D @stylexjs/unplugin
```

### Configure Vite

Update `vite.config.ts` with the StyleX unplugin and path resolution. Keep the StyleX plugin before the React plugin for Fast Refresh compatibility:

```ts title="vite.config.ts"
import path from "node:path";
import react from "@vitejs/plugin-react";
import stylex from "@stylexjs/unplugin";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [stylex.vite({ useCSSLayers: true }), react()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
});
```

### Add the StyleX directive

Create `src/index.css` and add the `@stylex;` marker:

```css title="src/index.css"
@stylex;
```

Import this stylesheet in your application entry point:

```tsx title="src/main.tsx"
import "./index.css";
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App";

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <App />
  </StrictMode>
);
```

### Configure path aliases in TypeScript

Update `tsconfig.json` (and `tsconfig.app.json` if using Vite project references) with path aliases:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### Add the design tokens

Install the shared tokens from the registry into `src/components/ui/tokens.stylex.ts`:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/stylex-tokens.json
```

### Install a component

Add a component using the shadcn CLI:

```bash
npx shadcn@latest add https://shadcn-cssinjs.com/r/button.json
```

Import and render the component:

```tsx title="src/App.tsx"
import { Button } from "@/components/ui/button/button";

export function App() {
  return (
    <div>
      <Button>Click me</Button>
    </div>
  );
}

export default App;
```

</Steps>
